## Dev Notes

### Architecture Context [Source: docs/architecture.md]

**OpenAI Chat Completions (Sec 5.6):**
- Model: gpt-4o-mini
- Mode: Function calling com strict: true
- Schema: extract_intent → { intent, entities, confidence }
- Timeout: 10s
- Custo: ~$1.80/mes

**Intent Classifier Pattern (Sec 13.3):**
```typescript
export async function classifyIntent(text: string): Promise<IntentResult> {
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      { role: 'system', content: SYSTEM_PROMPT },
      { role: 'user', content: text },
    ],
    tools: [{ type: 'function', function: extractIntentSchema }],
    tool_choice: { type: 'function', function: { name: 'extract_intent' } },
  });

  const toolCall = response.choices[0].message.tool_calls?.[0];
  if (!toolCall) {
    return { intent: Intent.CLARIFICACAO, entities: {}, confidence: 0, rawText: text };
  }

  return JSON.parse(toolCall.function.arguments);
}
```

**Data Models (Sec 4.2):**
- Intent enum: UPLOAD_ARQUIVO, CRIAR_EVENTO, CRIAR_REUNIAO, CANCELAR_EVENTO, AJUDA, CLARIFICACAO
- IntentResult: { intent, entities: IntentEntities, confidence, rawText }
- IntentEntities: { titulo?, data?, hora?, duracao?, participantes?: Participant[] }
- Threshold: confidence < 0.7 → CLARIFICACAO

**Error Handling (Sec 14):** Usar handleApiError(error, 'intent-classifier'). Se GPT falha, mensagem: messages.errors.gptFailed.
