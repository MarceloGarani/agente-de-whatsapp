**Error Handling (Sec 14):**
- AppError class com code, statusCode, userMessage, context?, originalError?
- handleApiError() mapeia ECONNREFUSED/ETIMEDOUT → SERVICE_UNAVAILABLE, 401/403 → AUTH_ERROR
- messages.ts contem TODAS as mensagens pt-BR centralizadas (ver architecture.md sec 14.2 para conteudo completo)

**Logger (Sec 15.1):**
- pino com campos padronizados: service, action, durationMs, intent, error
- redact: ['*.token', '*.key', '*.secret', '*.refreshToken']

**Coding Standards (Sec 13):**
- Funcional > OOP: funcoes exportadas, nao classes
- TypeScript strict: sem `any`, sem `@ts-ignore`
- Async/await: sem callbacks, sem `.then()` chains
- Named exports: sem `export default`
- Naming: arquivos kebab-case, funcoes camelCase, interfaces PascalCase, enums PascalCase com UPPER_SNAKE values, constantes UPPER_SNAKE_CASE

