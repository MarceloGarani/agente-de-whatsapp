## Story

**As a** user,
**I want** to cancel events or meetings by sending a message on WhatsApp,
**so that** I can manage my schedule and participants are notified automatically.

## Acceptance Criteria

1. `calendar.service.ts` implementa `deleteEvent(eventId)` via `calendar.events.delete` com `sendUpdates: 'all'`
2. Message router integrado: intent `cancelar_evento` → busca eventos matching → solicita confirmacao → cancela
3. Busca de eventos por descricao/data usando `listUpcoming` + filtro por titulo
4. Se multiplos eventos encontrados (AC-5.3), lista opcoes numeradas e pede selecao ao usuario
5. Confirmacao obrigatoria antes de cancelar: "Cancelar '[titulo]' em [data]? Responda sim para confirmar"
6. Apos cancelamento, confirmacao enviada: "Evento '[titulo]' cancelado com sucesso"
7. Para reunioes com participantes (FR-8), notificacao de cancelamento enviada pelo mesmo canal do convite original
8. Se evento nao encontrado, responde: "Nao encontrei nenhum evento com essa descricao"
9. Teste unitario: mock Calendar API (busca + delete) + fluxo de confirmacao

## Dev Notes

### Architecture Context [Source: docs/architecture.md]

**Fluxo de Cancelamento (Sec 6.5):**
```
"cancelar reuniao de sexta"
→ "Buscando seu evento..."
→ findEventsByTitle("reuniao", sexta)
→ Se 1 resultado: "Cancelar 'Reuniao' em DD/MM? Responda sim"
→ Se multiplos: lista numerada
→ Confirmacao: "sim"
→ deleteEvent(eventId, sendUpdates:'all')
→ "Evento cancelado com sucesso"
```

**Estado de Conversacao (Limitacao v1):**
Sem banco de dados, nao ha como persistir estado de conversacao entre mensagens. Usar `Map<string, PendingAction>` em memoria:
```typescript
interface PendingAction {
  type: 'cancel_confirm' | 'cancel_select';
  eventId?: string;
  events?: CalendarEvent[];
  expiresAt: Date; // 5min timeout
}
const pendingActions = new Map<string, PendingAction>();
```
Antes de classificar intent, verificar se ha pendingAction para o phoneNumber. Se sim, processar como resposta a acao pendente.

**Messages pt-BR (Sec 14.2):**
- `messages.prompts.cancelConfirm`: "Cancelar \"{titulo}\" em {data}? Responda \"sim\" para confirmar."
- `messages.prompts.multipleEvents`: "Encontrei {count} eventos. Qual deseja cancelar?\n{lista}"
- `messages.confirmations.eventCancelled`: "Evento \"{titulo}\" cancelado com sucesso."
- `messages.errors.eventNotFound`: "Nao encontrei nenhum evento com essa descricao."

**Limitacao v1:** Sem DB, nao ha registro de canal de convite original por participante. Calendar sendUpdates:'all' cobre emails. WhatsApp invites nao tem rastreamento de cancelamento.
