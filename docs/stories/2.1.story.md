## Story

**As a** user,
**I want** to connect my Google account to the assistant,
**so that** it can access my Drive, Calendar and Gmail on my behalf.

## Acceptance Criteria

1. `google-auth.ts` implementa OAuth2Client com `client_id`, `client_secret` e `redirect_uri` do env
2. GET `/auth/google` redireciona (302) para Google consent screen com scopes: `drive.file`, `calendar`, `gmail.send`
3. Parametros OAuth incluem `access_type: 'offline'` e `prompt: 'consent'` para garantir refresh token
4. GET `/auth/google/callback` troca authorization code por tokens via `oauth2Client.getToken(code)`
5. Callback exibe o `refresh_token` na tela para o usuario copiar e colar no `.env` (v1 single-user)
6. `getAuthenticatedClient()` retorna OAuth2Client configurado com refresh token do `.env`, renovando access_token automaticamente
7. Se refresh token estiver ausente ou invalido, loga erro e notifica via WhatsApp com instrucoes de re-autorizacao (EC-7)
8. Teste unitario: mock de OAuth flow verifica troca de code por tokens

## Dev Notes

### Architecture Context [Source: docs/architecture.md]

**Google OAuth 2.0 (Sec 5.2, 8.2):**
- Scopes: `drive.file`, `calendar`, `gmail.send`
- Flow: Authorization Code com access_type: 'offline', prompt: 'consent'
- Token storage: refresh_token em .env (v1 single-user)
- google-auth-library renova access_token automaticamente via refresh_token

**Auth Flow (Sec 8.2):**
```
1. Dev executa GET /auth/google (uma vez)
2. Browser abre Google consent screen
3. Usuario autoriza scopes
4. Callback GET /auth/google/callback recebe code
5. Troca code por { access_token, refresh_token }
6. Exibe refresh_token na tela → usuario copia para .env
7. getAuthenticatedClient() usa refresh_token do .env
8. google-auth-library renova access_token automaticamente
```

**Security (Sec 11.2):**
- Scoped OAuth: `drive.file` (apenas arquivos do app, nao full drive access)
- pino redact: refresh tokens nao aparecem em logs

**Error Messages (Sec 14.2):**
- `messages.errors.authError`: "Preciso que voce reconecte sua conta Google. Acesse: {authUrl}"
